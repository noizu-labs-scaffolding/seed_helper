## Key Files Requiring Setup

| File | Action |
|------|--------|
| `config/config.exs` | Set `:seed_helper, repo:` to your app's Ecto Repo module — read at **compile time**, so it must be set before the lib compiles |
| `priv/repo/migrations/*_setup_seed_helper.exs` | Call `SeedHelper.Migration.up(1)` / `down(1)` in a host-app migration |
| `priv/repo/seeds.exs` | Wrap seed files in `begin_session()` … `end_session()` |

`.meta/pointers.yaml` is generated by `doc-pointers build --write`; treat it as
output, not source. `.DS_Store`, `_build/`, `deps/`, `doc/`, `cover/` and
`mix.lock` are untracked (see `.gitignore`).
